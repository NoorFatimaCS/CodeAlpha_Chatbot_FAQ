# 🤖 AI-Powered FAQ Chatbot with NLP & Voice Support

An intelligent FAQ Chatbot developed as part of the **CodeAlpha Artificial Intelligence Internship**. This project uses Natural Language Processing (NLP) and Cosine Similarity to provide accurate answers to user queries regarding CodeAlpha's internship procedures.

## 🚀 Key Features
- **Intelligent Matching:** Uses TF-IDF Vectorization and Cosine Similarity for high-accuracy response matching.
- **Advanced NLP:** Integrated with NLTK for Lemmatization and Tokenization to understand varied user inputs.
- **Voice-to-Text Interface:** Built-in Speech Recognition for a hands-free user experience.
- **Dark/Light Mode:** Modern, professional UI with a customizable theme toggle.
- **Chat Management:** Features to start a "New Chat" and "Download Chat History" as a `.txt` file.
- **Interactive Suggestions:** Quick-action chips for frequently asked questions.

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Machine Learning:** Scikit-learn (TF-IDF, Cosine Similarity)
- **NLP:** NLTK (WordNet Lemmatizer)
- **Frontend:** HTML5, CSS3 (Glassmorphism), JavaScript (Web Speech API)
- **Deployment:** Hugging Face Spaces

## 📁 Project Structure
- `app.py`: The Flask server and AI logic.
- `faqs.json`: Dataset containing internship-related queries and answers.
- `templates/index.html`: Modern responsive UI.
- `requirements.txt`: List of dependencies.
